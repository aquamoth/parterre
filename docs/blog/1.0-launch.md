# My AI agents left 11 worktrees behind. I built a graph to see them.

![parterre showing branches, tags, three worktrees and four open pull requests](https://raw.githubusercontent.com/aquamoth/parterre/main/docs/images/1.0/hero-light.png)

Last month I ran `git worktree list` and counted eleven. Some were agents still working,
some were pull requests I'd checked out to review, and a few I had simply forgotten.
`git log --graph` showed me hundreds of commits and none of what I actually wanted to know:
which branch is where, which worktree is on what, and which of them have open pull requests.

So I built **parterre**: every branch, tag, worktree and pull request of a repository in one
picture, with the commits in between left out. It's free, open source, and runs on Windows,
Linux and macOS.

**[Download parterre 1.0](https://github.com/aquamoth/parterre/releases)**

## Why I built it

I've used git since 2013, when the company I worked for moved off Subversion. As a Windows
developer I already lived in TortoiseSVN, and TortoiseGit's *Revision Graph* became the one
feature I couldn't do without. Colleagues swore by other tools; I tried them and kept coming back.

Two things changed. I now work on Linux and macOS as much as Windows, where TortoiseGit doesn't
exist. And coding agents do a lot of my work now, each in its own worktree (I run mine in
T3 Code), so I'm juggling more branches and pull requests, mine and my colleagues', than ever.
I wanted that revision graph back, on every machine, and aware of worktrees and pull requests.

## Every worktree in one window

Each worktree shows up on the commit it has checked out. From its node you can go to it, open
its folder or a terminal there, or delete it when you're done. That last one is how I got
from eleven to four.

![A worktree's menu](https://raw.githubusercontent.com/aquamoth/parterre/main/docs/images/1.0/worktrees-light.png)

## Pull requests on the commits they propose

If `gh` is signed in, each open pull request is labelled on its branch's commit, with drafts
greyed out. Click a label to open it in the browser.

## Ahead, behind, and rebases

Select a branch and the commits between it and its upstream light up: green ahead, blue behind,
red where a force push would lose work. The status bar says `5|2`. Merge, rebase, cherry-pick,
reset, push and pull run from the node, and every dialog shows the git command it will run.

![A rebased branch and its upstream](https://raw.githubusercontent.com/aquamoth/parterre/main/docs/images/1.0/rebase-light.png)

And when the layout isn't the way you want it, drag it: the graph gives way, as if held by
weak magnets.

![Dragging nodes](https://raw.githubusercontent.com/aquamoth/parterre/main/docs/images/1.0/drag-light.gif)

## What it isn't (yet)

parterre isn't a full git client. You still stage and commit in your editor or terminal. The
macOS build isn't signed by Apple, so allow it once in *System Settings › Privacy & Security*.
On Windows, a download from GitHub shows "Windows protected your PC": choose *More info* →
*Run anyway*.

It's GPL-3.0, written in Rust, needs no account, and runs the git you already have.
[Here's exactly what it sends](https://github.com/aquamoth/parterre/blob/main/docs/privacy.md)
and how to turn it off.

## Try it

Grab the `.msi`, `.deb`, `.rpm` or `.dmg` from the
[releases page](https://github.com/aquamoth/parterre/releases), or `cargo binstall parterre`.
Then open it on the biggest, messiest repository you have.

If it draws something wrong or falls over,
[file an issue](https://github.com/aquamoth/parterre/issues). I read every one. And if
your graph looks interesting, I'd love to see a screenshot.
